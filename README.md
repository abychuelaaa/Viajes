# ✈️ Viaja con Dreamers

Bienvenido al repositorio oficial del sitio web de **Viaja con Dreamers**, una agencia de viajes dedicada a convertir cada destino en una experiencia inolvidable.

## 🌎 Sobre el proyecto

Este sitio web fue desarrollado para ofrecer a los clientes una forma rápida y atractiva de conocer los servicios, promociones y destinos disponibles en la agencia.

El objetivo principal es proporcionar una experiencia intuitiva que permita a los usuarios explorar opciones de viaje y contactar fácilmente con la agencia.

## ✨ Características

- Diseño moderno y responsivo.
- Integración con redes sociales.
- Sección de destinos turísticos.
- Información sobre paquetes de viaje.
- Formulario de contacto.
- Navegación sencilla e intuitiva.
- Optimizado para dispositivos móviles.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Swiper.js
- Netlify (Hosting)
